# Waná Knowledge Base ("The Brain")

Place operational and policy documents here so Customer Success, Marketing, and Booking agents can ground answers in your real rules—not guesses.

## Expected files

| File | Purpose |
|------|---------|
| `policies.txt` | Compensation, cancellation, cleaning, and guest-issue policies |
| `house-rules.md` | Property rules guests must follow |
| `pricing-logic.md` | How nightly rates, fees, and taxes are calculated |

## For agents

Whenever the user asks about a guest issue or pricing, search these files before answering.
